# Navigation, Consistency, and Mental Models

## Predictable Navigation
Navigation should help users understand where they are, what choices are available, and how to return to a previous or broader level. Labels should reflect users' goals rather than internal organizational structures.

Design guidance: keep navigation placement and naming consistent; use meaningful labels; show hierarchy when the information structure is deep; provide a clear path back; avoid changing navigation behavior unexpectedly between screens.

Reference: https://www.nngroup.com/articles/ten-usability-heuristics/

## Follow Familiar Conventions
Users bring expectations from other products and platforms. Following familiar interface conventions can reduce learning effort because users can transfer prior knowledge. Novel controls should be used only when the benefit outweighs the learning cost.

Design guidance: use conventional icons and interaction patterns; preserve platform expectations; add labels when an icon may be ambiguous; do not make common actions behave unexpectedly merely to appear unique.

Reference: https://www.nngroup.com/articles/consistency-and-standards/

## Design for Users Mental Models
A mental model is a user's internal understanding of how a system works. Interfaces are easier to learn when their concepts and behavior fit plausible user expectations. Large mismatches can cause repeated errors and confusion.

Design guidance: learn how intended users describe the task; organize features around user goals; test terminology and workflow assumptions; explain unavoidable system constraints in user-centered language.

Reference: https://www.nngroup.com/articles/mental-models/
