# Cognitive Load and Information Design

## Reduce Unnecessary Cognitive Load
Cognitive load in an interface is the mental effort required to use it. Interfaces become harder when users must remember many items, decode unfamiliar labels, repeatedly switch context, or scan excessive visual clutter. Designers should reduce avoidable mental work so users can focus on their actual goals.

Design guidance: simplify choices; use familiar language; keep instructions near the task; remove irrelevant visual competition; support recognition rather than recall; break complex work into meaningful stages when that improves comprehension.

Reference: https://www.nngroup.com/articles/minimize-cognitive-load/

## Chunk Related Information
Grouping related information into meaningful sections can make complex content easier to scan and understand. Chunking should reflect the task and information structure rather than being decorative fragmentation.

Design guidance: group related form fields; use clear headings; keep related actions close to the content they affect; avoid presenting a long undifferentiated wall of controls.

Reference: https://www.nngroup.com/articles/psychology-study-guide/

## Limit Overwhelming Choice
Many equally prominent choices can increase scanning and decision effort. Designers can use hierarchy, grouping, sensible defaults, progressive disclosure, and task-based navigation to emphasize the options most relevant to the current goal.

Design guidance: organize large menus into meaningful categories; prioritize common actions; avoid presenting advanced settings as if they are equally important to basic tasks; preserve access to less common options without allowing them to dominate the interface.

Reference: https://www.nngroup.com/articles/minimize-cognitive-load/

## Support Working Memory
Working memory is limited, so users should not be forced to carry important details mentally across screens. Externalizing information through visible context, summaries, labels, examples, and persistent state can make tasks easier.

Design guidance: show relevant prior selections; provide summaries before confirmation; keep instructions available at the point of use; avoid requiring users to memorize identifiers or values from previous screens.

Reference: https://www.nngroup.com/articles/working-memory-external-memory/
