# Conversational AI Interaction Guidance

## Set Appropriate Expectations
Conversational systems should communicate their scope so users understand what the assistant can and cannot reliably do. Overstating competence encourages misplaced trust.

Design guidance: state the domain of the assistant; disclose important limitations; provide examples of useful questions; distinguish design guidance from formal certification or professional advice.

Reference: https://www.nngroup.com/articles/ten-usability-heuristics/

## Ground Responses in Visible Context
When an AI assistant uses a controlled knowledge base, showing which sources or principles informed the response can improve transparency and help users judge the recommendation. Source display should not imply that a generated answer is automatically correct.

Design guidance: identify retrieved knowledge sources; keep recommendations tied to the supplied context; acknowledge when information is insufficient; encourage human review for consequential decisions.

Reference: https://www.nngroup.com/articles/ten-usability-heuristics/

## Design Useful Fallbacks
A chatbot should fail constructively when it does not understand a request or lacks relevant information. Repeating a generic error message leaves the user with no recovery path.

Design guidance: tell the user what information is missing; suggest how to rephrase or add context; avoid fabricating an answer; preserve the conversation so the user can continue from the failure.

Reference: https://www.nngroup.com/articles/ten-usability-heuristics/
